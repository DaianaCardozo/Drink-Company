# Drink Company

Drink Company es una landing page profesional para una academia de coctelería y bartending. El proyecto presenta cursos, talleres y servicios relacionados con el mundo de la barra, con una estética moderna, navegación clara y diseño responsive.

## Descripción

El objetivo del proyecto fue construir una página visualmente atractiva, funcional y orientada a la conversión, pensada para presentar la propuesta de una marca de formación en coctelería.

La landing incluye secciones informativas, presentación de cursos, llamados a la acción, contenido visual destacado y una estructura adaptable a distintos dispositivos.

## Funcionalidades

- Hero principal con mensaje de marca.
- Sección de cursos y talleres.
- Tarjetas informativas con detalles de cada propuesta.
- Diseño responsive para desktop, tablet y mobile.
- Navegación clara entre secciones.
- Botones de contacto orientados a conversión.
- Integración visual de imágenes, textos y llamadas a la acción.
- Estructura de componentes reutilizables.
