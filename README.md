# Drink Company

**Drink Company** es una landing page desarrollada con React, TypeScript y Tailwind CSS para una empresa especializada en servicios de coctelería para eventos.

El sitio presenta propuestas de barras móviles, coctelería de autor y atención profesional para bodas, celebraciones privadas y eventos corporativos. Su diseño combina una estética moderna y elegante con una navegación intuitiva, orientada a facilitar las consultas y solicitudes de presupuesto.

## Descripción

El objetivo del proyecto fue desarrollar una página web comercial que permitiera presentar los servicios de Drink Company, comunicar su identidad de marca y facilitar el contacto con potenciales clientes.

La landing está diseñada para ofrecer una experiencia visual atractiva, con una interfaz responsive, información organizada y llamados a la acción estratégicamente distribuidos.

## Funcionalidades

- **Hero principal:** presentación de la marca, sus servicios y principales propuestas de valor.
- **Servicios para eventos:** tarjetas de bodas y celebraciones, eventos corporativos, fiestas privadas y barras personalizadas.
- **Tarjetas interactivas:** efecto hover en escritorio y overlays táctiles en dispositivos móviles para consultar información detallada.
- **Diseño responsive:** interfaz adaptable a computadoras, tablets y celulares.
- **Navegación responsive:** menú de navegación con versión hamburguesa para dispositivos móviles.
- **Presentación de la empresa:** sección informativa sobre la experiencia, calidad y atención profesional de Drink Company.
- **Reseñas de clientes:** testimonios reales con acceso a la ficha del negocio en Google Maps.
- **Integración con WhatsApp:** botones de contacto con mensajes predefinidos para consultar servicios y solicitar presupuestos.
- **Enlaces a redes sociales:** acceso a los perfiles de la empresa.
- **Llamados a la acción (CTA):** botones distribuidos estratégicamente para facilitar la navegación y el contacto.

## Tecnologías utilizadas

- **React:** desarrollo de la interfaz y gestión de interacciones.
- **TypeScript:** tipado estático y organización del código.
- **Tailwind CSS:** estilos, diseño responsive y efectos visuales.
- **Vite:** entorno de desarrollo y generación de la versión de producción.
- **Git y GitHub:** control de versiones y gestión del repositorio.
- **Vercel:** despliegue de la aplicación web.

## Objetivo del proyecto

Este proyecto fue desarrollado para aplicar conocimientos de desarrollo front-end en una propuesta comercial real, priorizando tanto la experiencia de usuario como la presentación de los servicios.

Durante su desarrollo trabajé en la construcción de interfaces con React y TypeScript, el diseño responsive con Tailwind CSS, la implementación de interacciones adaptadas a dispositivos táctiles y la integración de canales de contacto externos.

También se buscó mantener una identidad visual consistente y una navegación sencilla, que permita a los usuarios conocer los servicios y solicitar presupuestos de manera rápida.

## Estado del proyecto

Proyecto funcional, en etapa de mantenimiento y mejoras continuas.
